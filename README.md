Netflix Data Analyzer 🎬📊

A Python-based data analysis project that explores the Netflix Movies and TV Shows dataset using Pandas, Matplotlib, and Seaborn.

📌 Project Overview

This project analyzes Netflix content to discover trends and patterns in movies and TV shows.

The analysis includes:

🎬 Movies vs TV Shows
🌍 Top 10 Countries
🎭 Top 10 Genres
📈 Content by Release Year
⭐ Netflix Ratings
⏱️ Movie Duration
🎥 Top 10 Directors
📊 Movies vs TV Shows by Year
📋 Overall Netflix Statistics

🛠️ Technologies Used
Python
Pandas
Matplotlib
Seaborn
Jupyter/VS Code
Git & GitHub
